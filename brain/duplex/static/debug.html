Server timeEventDetails and timing

Tool execution time measures the application handler, not the model's decision time. TTS first-byte time includes waiting for streamed text. Browser events use their own performance clock; server time is receipt time. Audio-delivery samples are throttled to one per half second per reply. This view does not expose a model's hidden reasoning.
